'@reuters-graphics/graphics-kit': minor
---

Add a blank option to the `make-ai-embed` mod so embed pages can be made for components that aren't ai2svelte graphics. The mod now asks what kind of embed to make. **Blank** prompts for a language and a slug (e.g. `embed-name`) and creates `pages/embeds/<locale>/<slug>/` with a `GraphicBlock` holding a placeholder where you wire in your own component. The block takes its props from the embed's entry in the embeds ArchieML doc (matched by `locale` and `slug`): `title`, `description`, `notes` and `altText`, plus optional `width` and `textWidth`, which default to `normal`. Bold placeholders show for the title, description and notes until that entry exists. The mod also copies the generic `reuters-graphics.jpg` to `src/statics/images/embeds/<locale>/<slug>.jpg` as a placeholder preview image, so the build doesn't fail on the missing image, and flags when making the page that the placeholder should be replaced before publishing. Blank embeds also trim the vertical margins of every graphic block, so components that render their own (e.g. `DatawrapperChart`) sit flush in the iframe. The mod now refuses the reserved `en/page` slug, which the `project-type` mod relies on, and refuses to run on blog projects, where embeds would fail to build because the blog conversion removes `locales/en/embeds.json`.
